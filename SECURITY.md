# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Simmit, please email **security@simmit.com** rather than opening a public issue.

We aim to acknowledge reports within 72 hours and provide a status update within one week.

## Scope

This repository contains placeholder SDK packages and example code. The Simmit service itself is the primary security-relevant surface. Vulnerabilities in the hosted API should also be reported to the address above.
